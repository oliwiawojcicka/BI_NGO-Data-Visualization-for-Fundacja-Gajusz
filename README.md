
# BI_NGO – Data Visualization for Fundacja Gajusz

## 📌 About the Project

This project was developed as part of the **#BI_NGO initiative** to support **Fundacja Gajusz**, a Polish non-profit organization helping children and families in difficult life situations.

The goal was to explore the relationship between **average annual gross salaries** and the **number of newborns left in hospitals** across Poland between 2007 and 2023.


## 🌐 Interactive Dashboard

Explore the interactive R Shiny dashboard:

filter data by voivodeship, and select different time
periods between 2007 and 2023.


## 📊 What I Did

I developed an **interactive data visualization application using R Shiny** that allows users to:

- Analyze the relationship between average salaries and newborn abandonment rates.
- Explore historical data from **2007 to 2023**.
- Filter results by Polish voivodeship (region).
- Select custom year ranges.
- Compare trends across different regions and time periods.

The number of newborns left in hospitals was standardized **per 10,000 births** to enable meaningful comparisons.

## 💡 Social Impact

The project aimed to help Fundacja Gajusz better understand regional and socioeconomic patterns related to newborns left in hospitals.

By transforming statistical data into interactive visualizations, the application makes it easier to explore trends, identify differences between regions, and support data-informed discussions about this important social issue.
